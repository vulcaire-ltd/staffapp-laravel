# Security policy

Report a vulnerability in `vulcaire/staffapp-laravel` by email to [hello@assignpoint.com](mailto:hello@assignpoint.com).

Please include the package name, the version you are running, and enough detail to reproduce the issue. Do not open a public GitHub issue for a security report. Do not include API tokens, webhook signing secrets, or personal data in the report.

We will acknowledge the report and coordinate a fix before any public disclosure.
